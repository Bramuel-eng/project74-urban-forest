# Project 74: Melbourne Urban Forest Canopy Analysis

**Student:** Bramuel Bukhuni  
**Unit:** SIT764 Team Project (A) - Trimester 1 2026

## Project Overview
Analyzing tree canopy coverage evolution in Melbourne from 2008 to 2021 to identify trends, forecast future coverage, and support climate adaptation goals.

## Data Sources
Tree canopy datasets from City of Melbourne Open Data Portal:
- Tree Canopies 2008
- Tree Canopies 2011
- Tree Canopies 2016
- Tree Canopies 2021

**Note:** Raw CSV files (1GB total) are not included in this repository due to size.

Download datasets from Google Drive:
- [2008 Dataset](https://drive.google.com/file/d/1v5LY0poj1CSQiyfVORr1Iv7cfzgOTn4K/view?usp=sharing)
- [2011 Dataset](https://drive.google.com/file/d/1zz30rn1lMaBb6zjkdw-5duO9IjI57q-X/view?usp=sharing)
- [2016 Dataset](https://drive.google.com/file/d/1hA3FJ9HaU_VXe9V21wENQDClZVDD30qG/view?usp=sharing)
- [2021 Dataset](https://drive.google.com/file/d/1jqDahRfnGbTX8AYmi2rZdMKwVgilZD3_/view?usp=sharing)

Place all CSV files in the `data/` folder to run the notebooks.
